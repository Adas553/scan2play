2. Description of Service

Scan2Play is an AI-powered music request platform for events. DJs create party sessions, guests request songs via QR code, and AI evaluates whether each request fits the party vibe; requests for the same song are counted as votes. The DJ plays the music from their own software — Scan2Play plays nothing; it only collects and filters the requests.
